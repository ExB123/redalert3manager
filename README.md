# Red Alert Tournament Manager — независимая версия

Первый рабочий каркас для переноса приложения из Adaptive.ai. Включает локальную копию базы из `rma9tjz4gp-data.sql`, API для чтения основных данных и интерфейс с тёмной боковой панелью.

## Требования
- Node.js 20 LTS или новее (рекомендуется Node.js 22 LTS)
- Git (необязательно для первого локального запуска; понадобится для GitHub)

## Запуск в Windows
1. Установите Node.js с https://nodejs.org/ (LTS) и перезапустите терминал.
2. Распакуйте проект в папку без кириллицы, например `C:\RA3Manager`.
3. Откройте эту папку в терминале (Проводник → адресная строка → `cmd` → Enter).
4. Выполните `npm install`.
5. Выполните `npm run dev`.
6. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

API сервера: http://localhost:3001/api/health

## Важно о данных
SQL-файл — SQLite-дамп (это подтверждают `PRAGMA` и `AUTOINCREMENT`). Он импортирован в `data/ra3-manager.sqlite`. В базе 21 таблица, включая 96 игроков, 32 команды, 256 обычных матчей, 1 732 рейтинговых матча, 12 турниров, 10 сезонов и 8 лиг.

Эта версия нужна для безопасного старта и проверки интерфейса на компьютере. Для полноценного публичного сайта с общей базой данных нужно следующим этапом перенести базу на управляемый PostgreSQL и настроить серверное размещение. Не публикуйте файл базы и резервные копии в открытом репозитории, пока не проверены данные и приватность. Для публичного GitHub лучше добавить базу в `.gitignore` и загружать её отдельно в защищённую базу.
