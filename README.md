# Red Alert Tournament Manager — независимая версия

Независимое React + Express приложение на основе исходного SQLite-дампа и PDF с 10 образцами интерфейса. Проект развивается в репозитории GitHub: https://github.com/ExB123/redalert3manager.

## Что уже работает
- Основные разделы: команды, игроки, рейтинг команд и игроков, рейтинговая лига, обычные матчи, турниры, сезоны, карты, статистика карт и фракций, звания, валюта, информация, достижения, медали и витрина достижений.
- Рейтинговые матчи: автоподбор для основного игрока, дополнительные пары, создание 20 пар без основного игрока, симуляция ближайших матчей и сохранение результата в SQLite.
- Завершение обычных матчей, продвижение победителя по турнирной сетке и начисление турнирных наград по GameConfig.
- Почта игрока: фильтры, статусы прочтения, трансферные и партнёрские предложения с действиями принять/отклонить.
- Резервные копии полной базы и восстановление из копии.
- Редактирование записей и связанных сущностей, сортировка таблиц, изображения команд и званий, цвета фракций и выделение призовых мест.
- Автоматические проверки API и production-сборки через GitHub Actions.

## Требования
- Node.js 22 LTS рекомендуется (Node.js 20+).
- Git — для получения обновлений из GitHub.

## Запуск в Windows
Откройте PowerShell в папке проекта и выполните:

1. Установите зависимости: npm install
2. Запустите приложение: npm run dev
3. Откройте адрес Vite, обычно http://localhost:5173.

API сервера: http://localhost:3001/api/health

Для остановки нажмите Ctrl+C в терминале.

## Проверка перед запуском
- npm test — запускает интеграционные smoke-тесты API, рейтинговых матчей, расчётов валюты, звания, почты и резервного копирования.
- npm run build — собирает клиентскую часть для production.

## Резервные копии
Откройте раздел «Настройки» → «Резервные копии базы» и нажмите «Создать копию». Для восстановления выберите полную копию и подтвердите действие. Старые записи BackupLog из исходного дампа могли содержать только часть данных; они доступны для просмотра, но не используются как полная резервная копия.

## Восстановление изображений
После получения обновлений из GitHub остановите запущенный сервер (Ctrl+C) и выполните:

    npm run restore:images

Скрипт проверяет URL логотипов команд, эмблем званий и лиг, карт, турниров и достижений. Успешно скачанные изображения сохраняются в client/public/images/imported, а в локальной базе меняются только адреса, для которых удалось получить файл. Недоступные ссылки записываются в image-restore-failures.txt.

После завершения снова выполните npm run dev. Сохраняйте папку client/public/images/imported вместе с проектом.

## Данные и публичное размещение
Исходный SQL — SQLite-дамп. В нём 21 прикладная таблица и служебная SeedLog; основные данные включают 96 игроков, 32 команды, 256 обычных матчей, 1 732 рейтинговых матча, 12 турниров, 10 сезонов и 8 рейтинговых лиг.

Локальная база и резервные копии не должны попадать в открытый GitHub. Публичный сервер с общей базой и полноценной авторизацией ещё требует отдельной настройки; не открывайте API в интернет до её завершения. Не все исторические функции можно достоверно восстановить автоматически: например, исходная база не содержит фракцию каждого игрока на момент каждого старого матча и не задаёт правила автоматического начисления опыта.
